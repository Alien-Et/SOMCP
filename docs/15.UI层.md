### RootGrantCard

```kotlin
@Composable
private fun RootGrantCard(
    granted: Boolean,
    onRecheck: () -> Unit,
    ...
) {
    // granted = true  → 绿色「Root 已授权」+「受限目录扫描与读取可用」
    // granted = false → 橙色「未获得 Root 权限」
    //                   + KernelSU / Magisk 授权指引
    // 两种状态都有「重新检测」按钮
}
```

探测频率：**30 秒一次**（不是 1 秒）。旧实现 1Hz 轮询会一天 fork
86,400 次 `su -c id`。

### 自动启动

两处：

1. **打开 App 自动启动**：`MainActivity.onCreate` 里 `McpForegroundService.start(this)`
2. **外部 Activity 后台启动**：`AutoStartActivity`（`NoDisplay` 主题，
   `exported=true`），`am start -n com.soreverse.mcp/.AutoStartActivity`
   即可在用户不点图标的情况下拉起服务

## 后台服务

### McpForegroundService

```kotlin
override fun onStartCommand(intent, flags, startId): Int {
    return when (intent?.action ?: ACTION_START) {
        ACTION_START -> if (startServer()) START_STICKY else START_NOT_STICKY
        ACTION_STOP -> { stopServer(); START_NOT_STICKY }
        else -> START_NOT_STICKY
    }
}
```

**注意**：只有启动成功才返回 `START_STICKY`。旧实现无条件 `START_STICKY`
会让每次重启都变成崩溃循环。

前台通知常驻，含服务状态与停止按钮。

### BootReceiver

监听 `RECEIVE_BOOT_COMPLETED`，`SettingsStore.bootAutoStart` 为真时开机拉起服务。

## 权限

`AndroidManifest.xml` 声明：

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | MCP HTTP 服务 |
| `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | 局域网地址探测 |
| `WAKE_LOCK` | 保活 |
| `SYSTEM_ALERT_WINDOW` | 悬浮窗（可选） |
| `POST_NOTIFICATIONS` | 前台服务通知 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` | 前台服务 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 保活引导 |
| `RECEIVE_BOOT_COMPLETED` | 开机自启 |
| `REQUEST_INSTALL_PACKAGES` | 应用内更新 |
| `QUERY_ALL_PACKAGES` | 已安装应用枚举（AppListGuard 用） |

**没有任何存储权限**（`READ_EXTERNAL_STORAGE` / `MANAGE_EXTERNAL_STORAGE` /
`READ_MEDIA_*` 全部没有）。这就是为什么 `/sdcard` 下的文件非 root 读不到。
